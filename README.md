  Esse projeto foi criado no meu primeiro semestre da Faculdade, o objetivo da atividade era desenvolver uma plataforma 
de classificados on-line, onde as pessoas possam realizar consultas e cadastrar anúncios de produtos. A ideia era criar 
as paginas de forma estática - Front End.
  O tema era livre, optei por criar um site de Hospedagens. O objetivo era implementar páginas que compõe o site, sendo 
página inicial com menu, pagina dos produtos/serviços anunciados, pagina de detalhes do anúncio, página para cadastros de
novos anúncios e uma página Portifólio, contendo informações do aluno.  
  Pré-Requisitos: As páginas que compõe o site deveria ser implementadas utilizando HTML5  e CSS, para melhorar a estilização 
  também utilizei BOOTSTRAP.
